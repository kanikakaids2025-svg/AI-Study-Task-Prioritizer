# AI Study Task Prioritizer

## AI Problem Design – Internship Task 1

### 1. Problem Statement

Students often struggle to manage multiple assignments, examinations, and project deadlines. This project proposes a system that helps students prioritize their academic tasks based on urgency, difficulty, and estimated completion time.

### 2. Target Users

* College and university students
* School students
* Students managing multiple assignments and examinations

### 3. Proposed Solution

The proposed system collects task details such as task name, deadline, difficulty level, and estimated completion time. It then ranks tasks according to their priority and recommends which task to complete first.

### 4. Data Source

The initial prototype will use manually created sample task data. A suitable public student time-management dataset may also be explored through Kaggle: https://www.kaggle.com/datasets

Any selected dataset will be checked for relevance and suitability before use.

### 5. Constraints and Limitations

* Incorrect task details may lead to unsuitable recommendations.
* Students have different study habits and abilities.
* The system may not account for unexpected personal circumstances.
* Recommendations should be reviewed by the student.
* Personal information must be handled responsibly.

### 6. Success Criteria

* Priority Ranking: Whether urgent tasks appear near the top.
* Deadline Compliance: Whether recommendations help users complete tasks on time.
* User Feedback: Whether students find the recommendations useful.
* Task Completion Rate: The proportion of tasks completed by their deadlines during testing.

### 7. Evaluation Approach

Test the prioritization method using sample tasks with different deadlines, difficulty levels, and estimated completion times. Compare its recommended order against a manually prepared reference order and record any errors.

### 8. Expected Outcome

The system aims to help students organize academic work, focus on urgent tasks, and manage their study time more effectively.

### 9. Current Project Status

This repository documents the proposed AI problem, intended users, data source, constraints, and evaluation plan. Actual implementation and performance evaluation are future steps.

### 10. Ethical Considerations

Student information should be kept private. Recommendations should support student decision-making rather than replace personal judgment.
